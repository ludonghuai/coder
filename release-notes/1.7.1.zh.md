## 1.7.1 — 内核跟上上游（0.12.77）

这一版**只换内核，界面没动**。装完之后 AI 的行为会有些变化，因为包内 thincoder 从 0.12.76 升到 **0.12.77**。

### 你可能会感觉到的

| 变化 | 说明 |
|---|---|
| **思考块默认展开** | 不用再手点，推理过程直接铺开 |
| **嵌套子代理每行标身份** | 多层子代理时能看出"这行是谁在干活"，状态词也带上了 |
| **子代理思考时标签不再被冲掉** | 之前思考态会覆盖子代理名字，已修 |
| **队列消息显示为待处理带** | 排队的消息在输入框上方可见（VSC 端） |
| **子代理可以读项目声明（只读）** | 能读 `PROJECT-MANIFEST.json`，但**不能写**（写面仍归主 agent） |

### AI 的行为规则变了几条（提示词面）

| 规则 | 一句话 |
|---|---|
| FR38 | 需求必须先问，再进设计 |
| FR39 | 动手前先回答三个问题 |
| FR40 | **业务门禁失败就失败，不许自己造降级路径** |
| FR41 | 搜文档用声明的域，不拿 `grep` 硬扫 |
| FR42 | 项目声明"自己"，不是声明"产品" |
| FR46 | **一条规则一行**（16 档提示词里 290 行超长行被重写） |

### 一个判据修正

零写看门狗改成按**真实写入动作**计数，不再数"去重后的文件数"——以前反复改同一个文件会被误判成"没在写"。

## 怎么升

**自动**：已装 1.7.0 的，设置里点「检查更新」→ 提示 1.7.1 → 下载约 43 MB → 安装。

**手动**：下载下面的 `BaoCode-1.7.1-setup.exe`，覆盖安装即可（设置和项目都保留）。

## 不变的部分

- 安装包体积（还是约 43 MB —— 内置运行时的 Node 那 85 MB 是大头）
- 模型配置页、自动更新、内置隔离的规则
- 配置与数据位置（覆盖安装不动它们）

## 已知限制（与 1.7.0 相同）

- Windows 安装包**未签名** ⇒ SmartScreen 点「更多信息 → 仍要运行」
- macOS 版**未验证**
- 配置里 API Key 为**明文**（与 thincoder CLI 自身一致）

## 1.7.1 — 卡住时记下落点（上游）

这一版主要帮我们查清「执行过程中卡住、无响应」这类问题：macOS 上界面卡住时会自动记下卡在哪里，上传诊断时一起带上。另外修了聊天终端和分屏的几个问题。

诊断
- macOS 上界面超过 4 秒没有响应时，会自动记录当时各线程在做什么、卡了多久，写进日志；上传诊断时一起发送。平时几乎没有开销，只有真卡住时才采样，每次运行最多 3 次。
- 日志会记下每次是怎么退出的（正常退出、更新、被系统结束、崩溃）；上一次异常结束的，下次启动时会注明。
- 上传诊断时附带系统记录的报告：macOS 的崩溃、卡死后被强制退出、CPU 长时间占用过高，以及 Windows 的错误报告。文件名里的电脑名会去掉。

修复
- 聊天里的终端按对话分开：每个分屏显示自己项目的终端，宽度和对话一致。分屏标题栏上的终端、侧边栏、编辑器按钮作用于这个分屏自己的智能体。
- 拖动分隔线调整终端大小时，只在停下后告诉终端一次，不再刷出一屏重复的提示符。
- 打开远程项目或远程文件时，文件夹读得慢会显示「正在读取…」，选择框不再消失。
- 源代码管理：「生成提交信息」挪到提交按钮旁边；拖动提交信息上方的分隔线时，分隔线跟着鼠标走，双击恢复默认高度。
