## 1.7.1 — 内核跟上上游（0.12.77）

这一版**只换内核，界面没动**。装完之后 AI 的行为会有些变化，因为包内 thincoder 从 0.12.76 升到 **0.12.77**。

### 你可能会感觉到的

| 变化 | 说明 |
|---|---|
| **思考块默认展开** | 不用再手点，推理过程直接铺开 |
| **嵌套子代理每行标身份** | 多层子代理时能看出"这行是谁在干活"，状态词也带上了 |
| **子代理思考时标签不再被冲掉** | 之前思考态会覆盖子代理名字，已修 |
| **队列消息显示为待处理带** | 排队的消息在输入框上方可见（VSC 端） |
| **子代理可以读项目声明（只读）** | 能读 `PROJECT-MANIFEST.json`，但**不能写**（写面仍归主 agent） |

### AI 的行为规则变了几条（提示词面）

| 规则 | 一句话 |
|---|---|
| FR38 | 需求必须先问，再进设计 |
| FR39 | 动手前先回答三个问题 |
| FR40 | **业务门禁失败就失败，不许自己造降级路径** |
| FR41 | 搜文档用声明的域，不拿 `grep` 硬扫 |
| FR42 | 项目声明"自己"，不是声明"产品" |
| FR46 | **一条规则一行**（16 档提示词里 290 行超长行被重写） |

### 一个判据修正

零写看门狗改成按**真实写入动作**计数，不再数"去重后的文件数"——以前反复改同一个文件会被误判成"没在写"。

## 怎么升

**自动**：已装 1.7.0 的，设置里点「检查更新」→ 提示 1.7.1 → 下载约 43 MB → 安装。

**手动**：下载下面的 `BaoCode-1.7.1-setup.exe`，覆盖安装即可（设置和项目都保留）。

## 不变的部分

- 安装包体积（还是约 43 MB —— 内置运行时的 Node 那 85 MB 是大头）
- 模型配置页、自动更新、内置隔离的规则
- 配置与数据位置（覆盖安装不动它们）

## 已知限制（与 1.7.0 相同）

- Windows 安装包**未签名** ⇒ SmartScreen 点「更多信息 → 仍要运行」
- macOS 版**未验证**
- 配置里 API Key 为**明文**（与 thincoder CLI 自身一致）
