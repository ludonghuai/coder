## 1.7.2 — 跟上上游，修几处 Windows 的毛病

这一版把上游 1.6.0 线的四个修复并了进来，另修一处 git 面板在空仓库上会崩的问题。**界面布局没动。**

### 你可能会感觉到的

| 变化 | 说明 |
|---|---|
| **Windows 重新用 Impeller 渲染** | 上游修好之后切回来了；之前上的 Skia 让部分机器出白条 |
| **更新后不用重启浏览器** | 装新版时会替换浏览器已经启动的桥接宿主，扩展不再失效到重启为止 |
| **Markdown 预览滚动不再跳** | 看图时上方图片陆续加载，不再把正在读的文字往下推 |
| **表格里的链接能出气泡** | 单元格里的链接右键有菜单了 |
| **AI 改文件不再自动打开** | 文件变化仍列在面板里，但不再抢你的编辑区 |

### 一处行为变化

`CLAUDE_CODE_EFFORT_LEVEL` 环境变量**不再钉死** Claude 的思考强度——以前设了它，界面上怎么调都不生效；现在以界面选择为准。

### 一处修复（git 面板）

打开一个**还没有任何提交**的仓库时，git 面板会在构建期通知界面刷新，Flutter 会报「setState during build」。现在通知推到这一帧构建之后。

### 内核也跟着上游走了两版

包内的 thincoder 从 **0.12.77 升到 0.12.79**（核心 0.10.11 → 0.10.12）。这一段的改动主要在提示词与流程规则面，日常用法不变：

| 规则面 | 一句话 |
|---|---|
| 三层原则（persona / 共同 / 纪律） | 重新分层，重复的句子合并，边界写清 |
| 轻通道准入 | 改成让用户**做选择题**，而不是 agent 自己判 |
| 项目根解析 | 单一来源，不再有第二处推算 |
| 台账 | 起点收界，跨项目不再串 |
| 体量帽残留 | 清掉十三处自相矛盾的旧帽句 |

## 怎么升

**自动**：已装 1.7.1 的，设置里点「检查更新」→ 提示 1.7.2 → 下载约 43 MB → 安装。

**手动**：下载下面的 `BaoCode-1.7.2-setup.exe`，覆盖安装即可（设置和项目都保留）。

## 不变的部分

- 安装包体积（约 43 MB——内置运行时的 Node 那 85 MB 是大头）
- 模型配置页、自动更新、内置隔离的规则
- 配置与数据位置（覆盖安装不动它们）

## 已知限制（与 1.7.1 相同）

- Windows 安装包**未签名** ⇒ SmartScreen 点「更多信息 → 仍要运行」
- macOS 版**未验证**
- 配置里 API Key 为**明文**（与 thincoder CLI 自身一致）

## 1.7.2 — 手机上的 Bot，分屏各自带侧栏（上游）

这一版的重点是手机上的 Bot：像人一样和你聊天的智能体，跑在你的电脑上，在手机上和它们对话。另外，分屏可以各自带侧边栏、拖动换位置，还修了一些问题。

Bot（在手机上用，需要这一版桌面端）
- 每个 Bot 有自己的名字、头像、性别、签名、说话风格和模型。默认有一个助手，也可以自己新建。
- Bot 能做什么由你逐项打开：照看你的 agent（查看、停止、重试、归档、发消息、开新的）、使用你的浏览器、在 agent 等你或出错时主动告诉你。
- Bot 可以上网，会记住你说过的事；在 设置 → 模型 里打开图片模型后还能生成图片。你发给它的图片它也能用，比如拿来当头像。
- Bot 不读写电脑上的项目文件，项目里的活交给 agent。

新功能
- 分屏时每个对话有自己的侧边栏，单独显示或隐藏。
- 拖动分屏的标题栏，可以把它放到另一个旁边，或者两个互换位置。把项目的「新建 agent」拖到分屏上，会在旁边开一个新的。
- 侧边栏里的文件可以用默认应用打开，菜单里还有在终端、文件管理器里打开和复制路径。
- IDE 左侧活动栏底部加了设置按钮。
- 手机上能看到 agent 生成的图片、工具返回的图片、浏览器的每一步操作，以及目标和本轮用量。
- 内置核心和 Claude Code CLI 2.1.293 对齐。

修复
- 进程还在启动时点「立即发送」，会等它准备好再发。
- 读取上游 key 失败不会被记住，也不会冲掉期间新设的 key。
- 浏览器发来的长消息收全了才处理。
- 用量以字符串返回的模型，用量能正确显示。
- 从输入框复制时保留标签，粘贴到别的应用是纯文本。
- Markdown 文件的改动默认显示渲染效果，点一下看 diff；侧边栏的文件树带 Git 状态。
- Git 日志的图完整显示，详情可以复制，分支也显示出来。
- 提交面板的勾选框看得清，改动可以按列表或树显示，窗口窄时按钮不再挤出去。
- Windows：分屏标题栏的按钮作用于各自的 agent，和 macOS 一样；改用 Skia 绘制，画面更快、更省内存。
