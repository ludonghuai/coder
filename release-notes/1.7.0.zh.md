## 这一版最重要的变化：**装完就能用**

以前的安装包里没有 thincoder，你得先装 Node.js、再 `npm i -g thincoder`，会话才能跑起来。1.7.0 起，**安装包自带一份 thincoder 运行时**（Node + CLI），装完打开、配一个 API Key 就能对话。

代价是安装包变大：**21 MB → 43 MB**。换来的是一步都不用做。

---

## 怎么装

1. 下载下面的 `BaoCode-1.7.0-setup.exe`（43 MB）
2. 双击 → SmartScreen 弹窗点 **更多信息 → 仍要运行**（安装包没买签名证书，是正常的）
3. 装完打开，点「打开文件夹」选一个代码目录
4. **设置 → 模型（thincoder）→ 添加 provider**，填 名字 / Base URL / API Key / 模型名，保存

详细图文（含常见问题）：[中文安装指南](https://github.com/ludonghuai/coder/blob/main/docs/install-zh.md)

## 这一版都改了什么

**模型配置面（新）**
- 设置里新增「模型（thincoder）」页：列出当前 provider、当前模型、会话报告的候选模型
- 可以直接加 / 改 provider，不用再去终端敲命令
- 写入只动 `providers` 与 `defaultModel`，配置文件里其它键**一个都不碰**
- 密钥只显示末四位；保存遇到并发改动会**零写入**并留一份 `config.json.bak-<时间戳>`
- 保存后不会偷偷重启你的会话，只提示 + 给一个「重新打开会话」按钮

**自动更新（新）**
- 应用从本仓的 GitHub Release 读清单、用自有公钥验签
- 上游（baocode.dev）发的版本**不再接管**你的用户
- 检查更新失败不会影响使用，可以手动下载覆盖安装

**内置运行时（新）**
- 发行版自带 thincoder，只给 BaoCode 自己用，**不往系统 PATH 里塞东西**
- 内置副本的数据（会话 / 配置 / 日志）关在应用自己的目录里，不碰你的 `~/.thincoder`
- **开发/调试环境完全不受影响**：`flutter run` 仍然走 PATH、仍然和终端共用 `~/.thincoder`

## 已知限制

- **Windows 安装包未签名** ⇒ SmartScreen 会拦一次，点「更多信息 → 仍要运行」
- **macOS 版未验证**：打包脚本已按设计写好，但没在 Mac 上跑过（签名 / 通用二进制 / 包结构）
- **没装 Claude Code 也能用**：切 Claude Code 内核仍需要它自己的 CLI；thincoder 内核不需要
- 配置里的 API Key 是**明文**存在配置文件里（与 thincoder CLI 自身一致），没有接系统凭据库

---

## 需要的系统环境

- Windows 10 / 11 x64
- Microsoft Visual C++ 运行库（x64）——绝大多数机器已有；缺的话装一次 [vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe)
