New

- The thincoder kernel is in: messages queue while it works, a sent message is edited by rewinding to its turn, sessions rename, files revert per turn, and the mode and model menus follow what the kernel reports
- A thincoder session opens on a kernel that is already up: a warm process and its handshake are paid for ahead of time, and the CLI now builds a session in about 0.19 s instead of 1.5 s
- `@` lists the project's files (subfolders and paths outside the project too), and `/` opens the command menu anywhere in the message
- Subagents may run on another upstream's model through the proxy; an agent stopped at its usage limit goes on once it resets
- Queued messages send while the agent works, leaving background tasks at work

Improved

- A streaming delta rebuilds one row, not the history
- A kernel switched back to is the one still running, with no handshake to wait for
- The `@` menu no longer re-walks the project per keystroke, and a two-key chord starts inside the message box

Fixed

- A chord's second key is this window's even when nothing inside has focus
- The automatic fetch runs with the chat alone
- A kernel switched to starts at once, without waiting a frame
- A drag in a zoomed preview selects under the pointer
- The side panel's action row counts all three buttons
- A definition in a remote project opens on its host, its path read as the host spells it
