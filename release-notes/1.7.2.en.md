## 1.7.2 — Keeping up with upstream, and a few Windows fixes

This release merges four fixes from upstream's 1.6.0 line, and fixes a git panel crash on a repository with no commits yet. **The layout is unchanged.**

### What you may notice

| Change | What it means |
|---|---|
| **Windows renders with Impeller again** | Switched back now that upstream fixed it; the Skia fallback left a white strip on some machines |
| **An update no longer needs the browser restarted** | The installer replaces the browser host a running browser started, so the extension keeps working |
| **Markdown previews no longer jump while scrolling** | Images above the view load without pushing the text you are reading down the page |
| **Links in table cells get their menu** | A right click on one now offers the link's actions |
| **An agent's edit no longer opens the file** | Changes still list in the panel, but no longer take over your editor |

### One behaviour change

`CLAUDE_CODE_EFFORT_LEVEL` no longer pins Claude's effort — setting it used to override the UI silently; the UI's choice wins now.

### One fix (the git panel)

Opening a repository with **no commits yet** notified the UI during a build, which Flutter reports as "setState during build". The notification now lands after that frame's build.

### The bundled core moved two releases

The thincoder inside goes from **0.12.77 to 0.12.79** (core 0.10.11 → 0.10.12). These changes sit mostly in the rules the agent follows rather than in what you do day to day:

| Where | In a sentence |
|---|---|
| Prompt layers (persona / common / discipline) | Re-cut so each layer answers one question; repeated lines merged |
| The light channel | The agent now offers you a choice instead of deciding for itself |
| Project root resolution | One source of truth, no second guess |
| The ledger | Bounded at the start; projects no longer bleed into each other |
| Leftover size caps | Thirteen sentences that contradicted each other are gone |

## How to update

**Automatic**: on 1.7.1, open Settings → Check for updates → 1.7.2 → about 43 MB → install.

**Manual**: download `BaoCode-1.7.2-setup.exe` below and install over the old one (settings and projects are kept).

## What has not changed

- Installer size (about 43 MB — the bundled Node runtime's 85 MB is the bulk)
- The model settings page, auto-update, the isolation rules
- Where the configuration and data live (an over-install leaves them alone)

## Known limits (unchanged from 1.7.1)

- The Windows installer is **unsigned** ⇒ SmartScreen: More info → Run anyway
- The macOS build is **unverified**
- API keys sit in the configuration **in plain text** (as in the thincoder CLI itself)

## 1.7.2 — Bots on the phone, a side panel per pane (upstream)

This release is about bots on the phone: agents that chat with you as a person does, running on your computer and talked to from your phone. Split panes also get a side panel each and can be dragged around, and a number of things are fixed.

Bots (on the phone, with this version of the desktop app)
- Each bot has its own name, picture, gender, signature, way of speaking and model. There is an assistant to start with, and you can make your own.
- You turn on what a bot may do, one thing at a time: look after your agents (see them, stop, retry and archive them, write to them, start new ones), use your browser, and tell you first when an agent is waiting for you or has failed.
- Bots can search the web and remember what you told them, and make pictures once an image model is turned on in Settings → Models. A picture you send one is theirs to use, as their own picture for instance.
- Bots do not read or write the projects on your computer: a project's work is an agent's.

New
- Side by side, each pane has a side panel of its own, shown or hidden there.
- Drag a pane by its title bar to put it beside another or swap the two. Drag a project's New Agent onto the panes to open a new agent beside them.
- A file in the side panel opens in its default app, with a menu to open it in the terminal or the file manager, or copy its path.
- The IDE's activity bar has a settings button at its foot.
- The phone shows the pictures an agent makes, a tool's pictures, each step in the browser, and the goal and the turn's usage.
- The built-in core is aligned with Claude Code CLI 2.1.293.

Fixed
- Send Now, pressed while the process is still starting, waits until it is ready.
- A failed read of a provider's key is not remembered, and no longer drops a key set meanwhile.
- A long message from the browser is handled once it has all arrived.
- Usage given as strings by a model now shows.
- Copying from the composer keeps its tags; other apps get the text.
- A Markdown file's changes show it rendered, the diff a click away; the side panel's file tree has the Git status.
- The Git log's graph shows whole, its details can be copied, and the branches show.
- The commit panel's check boxes can be seen, the changes show as a list or a tree, and the buttons no longer overflow a narrow window.
- Windows: side by side, each pane's title bar buttons act on its own agent, as on macOS; drawing is done by Skia, faster and with less memory.
