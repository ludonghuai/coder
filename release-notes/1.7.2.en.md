## 1.7.2 — Keeping up with upstream, and a few Windows fixes

This release merges four fixes from upstream's 1.6.0 line, and fixes a git panel crash on a repository with no commits yet. **The layout is unchanged.**

### What you may notice

| Change | What it means |
|---|---|
| **Windows renders with Impeller again** | Switched back now that upstream fixed it; the Skia fallback left a white strip on some machines |
| **An update no longer needs the browser restarted** | The installer replaces the browser host a running browser started, so the extension keeps working |
| **Markdown previews no longer jump while scrolling** | Images above the view load without pushing the text you are reading down the page |
| **Links in table cells get their menu** | A right click on one now offers the link's actions |
| **An agent's edit no longer opens the file** | Changes still list in the panel, but no longer take over your editor |

### One behaviour change

`CLAUDE_CODE_EFFORT_LEVEL` no longer pins Claude's effort — setting it used to override the UI silently; the UI's choice wins now.

### One fix (the git panel)

Opening a repository with **no commits yet** notified the UI during a build, which Flutter reports as "setState during build". The notification now lands after that frame's build.

### The bundled core moved two releases

The thincoder inside goes from **0.12.77 to 0.12.79** (core 0.10.11 → 0.10.12). These changes sit mostly in the rules the agent follows rather than in what you do day to day:

| Where | In a sentence |
|---|---|
| Prompt layers (persona / common / discipline) | Re-cut so each layer answers one question; repeated lines merged |
| The light channel | The agent now offers you a choice instead of deciding for itself |
| Project root resolution | One source of truth, no second guess |
| The ledger | Bounded at the start; projects no longer bleed into each other |
| Leftover size caps | Thirteen sentences that contradicted each other are gone |

## How to update

**Automatic**: on 1.7.1, open Settings → Check for updates → 1.7.2 → about 43 MB → install.

**Manual**: download `BaoCode-1.7.2-setup.exe` below and install over the old one (settings and projects are kept).

## What has not changed

- Installer size (about 43 MB — the bundled Node runtime's 85 MB is the bulk)
- The model settings page, auto-update, the isolation rules
- Where the configuration and data live (an over-install leaves them alone)

## Known limits (unchanged from 1.7.1)

- The Windows installer is **unsigned** ⇒ SmartScreen: More info → Run anyway
- The macOS build is **unverified**
- API keys sit in the configuration **in plain text** (as in the thincoder CLI itself)
