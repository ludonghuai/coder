This release brings a new look: the window is a base with cards floating on it, a lower title bar, and the sidebar, the chat and the side panel each a card; tabs can be dragged to reorder. The phone improves too: the computer can keep to direct connections with no relay; messages sent from the phone get plain text; bots work better. It also adds /fork, code blocks that lay out as they are written, back and forward on the mouse's side buttons, Gitee, and usage priced the way upstreams price. On the phone, 0.1.6 is recommended, and Direct Only needs it.

Window
- The window is a base with cards floating on it: the title bar is lower (30), the sidebar, the chat and the side panel are each a card with a gap between them, and the corners and colors are tiered. A dark theme's window base no longer covers the theme's color; the cards sit a step above it.
- Tab strips are segments: editor and side panel tabs read as tabs, a scrolled strip's corners are not cut, and no overview ruler runs down the edge.
- Editor and side panel file tabs can be dragged to reorder.
- The side panel's tab names are 12 and their icons 13; the panel goes narrower, and each conversation in it has its own Git log, its changes folded under it.
- The input's and bubbles' outlines take their own hue, not a theme's border; the room above the chat's first message lines up with the room above the input.
- New Chat is a card, hovered as rows on cards are; themes and language servers in the extensions view are segments.

Phones
- Settings → Mobile → Relays has Direct Only: no relay at all, the phone connects to the computer's own addresses; for a computer with a public IP or a port forwarded on the router. The UDP port is yours to set (1024–65535, 47100 by default), and the computer's public addresses are shown there.
- On the phone, 0.1.6's computer page shows the computer's relay setting, port and addresses, and takes addresses of your own ("name or IP:port", a dynamic name for one), with a test of each.
- When you write from the phone, the agent is told, unseen, that you are on the phone, and replies in plain text that reads well there; back at the computer, it goes back to its usual formatting. You never see these notes, and the system prompt is left as it is, so the prompt cache holds.
- A bot no longer gets stuck on a question no one can answer; it asks you in its own words.
- Bots get the tools that work with no one at the computer, your own MCP servers included.
- What a bot hears of the agents follows rules (WATCH.md in its folder): wake it, only have the phone tell you, or ignore; woken with nothing to say, it stays silent.
- Projects' pins are shared between the computer and the phone.
- A deleted bot's leftover folder no longer shows as a project in the sidebar or in the phone's Files.

New
- /fork in the input forks the conversation and opens the copy.
- The mouse's side buttons go back and forward: out of a subagent, between changes and the Git log, out of the settings, or to the agent selected before. The IDE's title bar has Back and Forward beside its search box too.
- Formulas in the chat select whole and copy as their TeX.
- baocode://file/ links open a file at a line, as vscode://file/ does.
- Go to definition in Vue files.
- Gitee is supported; a self-hosted GitLab works over http and with certificates you trust.
- Usage is priced the way upstreams price: bands by prompt length, hours of the week (DeepSeek's off-peak discount), service tiers, fees per call and per tool use. Calls under way show in the calls list too.

Improved
- A code block being written lays out and colors only what changed, so long answers no longer slow as they grow; a new theme recolors the code at once.
- An edit's diff is inline, not side by side.
- Search results follow their files as they change.
- An edit's file header and a code block's title take less room.
- On Windows, the system proxy is read without starting reg.exe.

Fixed
- Home and End in the markdown editor go to the line's ends; an input method reattaches when focus comes back to the input.
- On a Git before 2.13, stashing goes through `stash save` instead of failing.
- A request Claude Code gives up on (a timeout, an interrupt) is now cancelled upstream too, and kept as cancelled.
- Editing settings.json with many models no longer hangs the window (it took seconds on Windows).
- Very long lines in the terminal no longer freeze the app.
- On Windows, selecting text with a dictionary or copy tool no longer resets the zoom to 100%.
- After the mouse button is let go outside the window, scrolling the chat no longer selects text.
- An SSH host's close button is back at the end of the title bar.
- On Windows, some crashes that ended the app outright now leave a crash report.
