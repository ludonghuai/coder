# 会话治理（session-governance）需求

> 板块：会话治理（`lib/chat` 的会话面 + `lib/kernel` 的能力门 + ACP 会话方法）· 范围仓：baocode（含声明的 thincoder 检出）。
> 状态：需求（用户 2026-10-20 00:02「拆两拨做吧，允许 rename」）· A1（rename + revert）已收口；A2（rewind，F3）= 本批，设计已过评审、待实施。
> 来源：用户 2026-10-19 23:56 起「我们如何安排任务」→ 差距表会话治理行（Claude 有 fork/回退/重命名，thincoder 只有存档级 list/load/resume）→ 用户裁定拆两拨并允许动外仓。

## 1. 模块目标

让"会话"这一层在两个内核上**可管理且语义一致**：会话可重命名、回合造成的文件改动可回退。判定标准是"同一个操作，Claude 与 thincoder 用起来没有差别，且终端与桌面看到同一份事实"。

## 2. 功能点

### F1 会话重命名

1. 任意会话可改标题（运行中的会话也可，不打断回合）。
2. **单一来源 = 内核的会话记录**：桌面会话列表与终端 `session list` 读到同一个标题。
3. 手动改过的标题**粘住**：自动标题生成（内核 `generate-title` 一类机制）不得覆盖手改标题。
4. 空标题或纯空白 ⇒ 拒绝并保留原值（不静默写成空）。

### F2 回合级文件回退

1. 对任一**已结束的回合**，把"从该回合起"内核改过的文件恢复原状（含该回合之后的回合；语义与 `RevertsChanges.revertChanges(sinceTurn:)` 一致）。
2. **单一来源 = 内核的文件撤销栈**（thincoder `undo-stack` 的快照；Claude 的检查点）：桌面回退与终端 `/undo` 操作同一份快照，不另建宿主快照。**「同一份」= 同一实现（进程内撤销栈）**；每会话一进程，不做跨进程共享对象——终端进程里改过的文件不在桌面回退面（若需要，另立需求）。
3. 恢复规则：有快照的文件写回快照内容；"文件在写前不存在"（快照为创建态）⇒ 删除该文件。
4. **跳过而不是误伤**：某个被记录的路径在回合之后又被改动过（内容哈希与内核记录的写后值不符）⇒ 跳过该文件并在结果里列出，不覆盖。
5. **不可回退项如实报出**：超单条上限（内核快照有 10MB 上限）或已被逐出（栈有 50 条 / 64MB 预算，最旧先出）的条目 ⇒ 记为"无法回退"，结果里列出，不假装成功。
6. 回退前**弹确认**：列出文件数、文件清单与"将丢弃回合后改动"的提示。
7. 与 Git 无耦合：撤销栈是文件级快照，非 Git 工作区同样能回退。

### F3 编辑已发消息（rewind）

1. **编辑并重发**：对一条**本进程创建**的用户消息，可就地编辑并重发——对话从该消息起截断，编辑后的文本作为新回合发送；该消息之前的对话与**文件内容**保持不动（文件回退是 F2 的独立动作）。
2. **只对本进程创建的回合生效**：重放/加载进来的历史消息（无回合键）不可编辑——v1 明确不做；界面给一条提示，对话不变（宿主现有 `editMessage` 的「否」分支是静默的，本批补上可见面）。
3. **槽的原子性**：每个槽同时只有一个活写者（槽认领）⇒ 截断在活会话内完成并随下一回合存档写入槽；终端**下一次** `session/load` 看到截断后的历史；已加载同一槽的另一个进程不会实时看到（不同进程，不做实时同步）。
4. **撤销栈**：被截断回合的文件条目**保留**（其 ordinal 仍 ≥ 被回退回合下界 ⇒「从该回合起」的回退仍覆盖它们）；只移除被截断回合的**回合索引键**（不再可作回退起点）。
5. **在飞不可编辑**：有回合在飞时，编辑入口不可用（宿主先 `stop()`；内核拒绝则提示）。
6. **拒绝可见**：rewind 被拒（未知回合 / 在飞 / 只读历史）⇒ 界面一条提示，不静默。

**F3 边界**：不做文件回退（= F2）；不做 fork；不做消息级（非回合级）截断；不做自动轮的编辑；不做跨进程实时同步。

## 3. 边界（明确不做）

- **不做 fork**：依赖 ACP 扩展与内核会话复制语义，独立批。
- **不替代 Git**：不提交、不 stash、不改 index；SCM 的逐文件 discard 照旧。
- **不做跨回合的选择性（逐文件挑选回退）**：v1 只做"从某回合起"的全量回退；逐文件挑选留给后续需求。
- **不改 Claude 内核的既有行为**：它已实现 `RenamesSession` / `RevertsChanges`，本批只做**非回归**。
