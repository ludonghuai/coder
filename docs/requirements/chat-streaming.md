## 1. 模块目标

让**流式回复期间的界面保持跟手**：模型每吐一个字，只重建与该字相关的部分，界面开销不随对话变长而增大。今天是反过来的——每个增量都重算整棵历史，所以长对话越聊越涩。折叠只隐藏过程，不隐藏用户要看的结果（跨回合同样）。

## 2. 事实基线（2026-10-17 实读）

- 每收到一个文本增量，`lib/chat/chat_session.dart:159-163` 通知一次；`lib/chat/chat_history_view.dart:1214` 随 `setState`。
- `build` 里 `_built = null`（`chat_history_view.dart:2090`），整棵历史重算（含 `cacheExtent: 900` 内的行，`:2219`）；流式时约 **20–60 次/秒**。
- 同频连带开销：折叠整体重算（`step_folds.dart:65-70`，成本 ∝ 会话条目总数）与流式消息 markdown 整篇重解析（`markdown_view.dart:83-98`，长回复退化为 O(L²)）。**图片收集 `_images`（`chat_history_view.dart:2122`）不是每增量成本**：它只作为 `ChatImages.all` 的回调传入，打开图库时才按需调用一次（O(N)）——缓存要防的是重复按需收集。
- 已做对的地方（本批不得破坏）：列表已虚拟化（`SuperListView.builder:2214`）；非流式 markdown 有缓存（`markdown_view.dart:69-98`）；折叠隐藏行按实例记忆化（`chat_history_view.dart:1763-1793`）。

## 3. 功能点

**F1 流式增量只重建该重建的部分**：一个文本增量到达时，重建范围不随历史长度增长——外壳（滚动条主题、选择区、骨架容器）不进入每增量的重建路径，只有正在流式的那一条**（思绪连跑合并显示时，为它所在的那一行）**及其必要的布局参与。
验收（可机检）：同一段固定脚本回放（120 个增量、每段 8 字）下逐次计数——**`ChatFindRow` 重建 0 · `SuperListView` 0 · `SelectionArea` 0 · `ChatItemView` 恰 1**；且**20 回合与 200 回合两种历史下逐项相等**；**文本确实在更新**——回放过程中 `MarkdownView` 收到的输入数据每次都是最新全文（渲染块可按 F3 的节流节奏），回放结束后可见文本与一次性写入的全文一致。改前 / 改后同法各给一份读数（改前必须实测，不得估）。

**F2 折叠不再全量重算；图片集合不重复收集**：尾部增量只重算受影响的那一回合；图片集合按「条目数 + 末条身份」缓存（防的是打开图库时的重复 O(N) 收集，不是每增量成本）。
验收（可机检）：① 增量回放期间，折叠计算次数不随历史长度线性增长，且与全量计算逐项相等（对拍）；② 同一历史下连续多次取图片集合 ⇒ 实际收集次数为 1（缓存命中）。

**F3 流式 markdown 不做整篇重解析**：按块缓存（只解析末尾未闭合块）或节流（≥50ms）二选一，由设计定；选节流须证明不会丢失最终态。
验收（可机检）：长回复（≥5000 字符）流式期间，该消息的解析次数上界可数；流式结束后渲染结果与一次性解析完全一致。

**N1 基线可复现**：本批必须给出**同一脚本、同一台机器**上的改前 / 改后读数（构建次数、解析次数；可选附加帧耗时）。

**F4 折叠按回合分界，跨回合不吞答案**：完成回合的工作折成一行，但只折**本回合自己的** work、折到**本回合自己的答案之前**；unprompted 回合（子代理回调后主 agent 自动续写）是独立回合，它自己的 work 可折、答案保留，上一回合的答案不得被折走。
验收（可机检）：用户回合回答 + unprompted 回合回答并存时，两条答案都可见；上一回合的 work 仍折成一行；子代理回调汇报落地后，上一回合答案不被折走；单回合内「中间回答被折」的既有语义不变；既有性能读数（六类外壳 0/0、`ChatItemView` 每增量 1、A4 恰 1 帧）不回退。
边界：只改折叠的回合边界；不改 unprompted 回合语义、折叠视觉形态、粘顶/选择区/滚动锚定；不改事件形态（`KernelEvent` / `Transcript`）。重载后旧回合仍按提示词规则（退化，用户 2026-10-18 接受，另批再议）。

## 4. 边界（明确不做）

- 不改视觉与交互：粘顶消息、跨重建的选择区、滚动锚定（`_BeforeLayout` / `_StickyFollower`）、`cacheExtent` 语义保持。
- 不改数据模型（`ChatSession` / transcript 的事件形态零动）；不改内核侧任何代码。
- 不引入新依赖、不换列表实现（`SuperListView.builder` 保留）。
- 不做整档重构：`chat_history_view.dart` 若必须拆，**只拆本批需要的那一小块**，并在设计里写明行数预算。
- 不动非流式路径的既有缓存策略。
