## 这一批要解决什么

**不是修产品缺陷，是修"验收的度量衡"。**

今晚三个批（结构拆分、btest、上游适配）**每一个**都被迫写同一条判据：「基线红项集合与改后逐条一致、无新增失败」。所以每次交付都要多跑一次基线、多核一遍红单。

根因：全量测试在 Windows 上本来就红，红因是**夹具写死 POSIX 形状的路径**（`/p/a.dart`），而 Windows 上 `p.join` / `absolute` 产出带盘符与反斜杠的形状（`D:\p\a.dart`）。产品代码没错，是断言写死了一种操作系统的拼写。

做掉这批之后，全量跑的判据回到一句话：**全绿**。
